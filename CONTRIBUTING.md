# Contribuir

Usa Node.js 22 o posterior. Ejecuta `npm ci`, `npm run check` y `npm test`.

Para modificar la interfaz, edita `panel.html` y `panel.css`. Ejecuta `npm run build` e incluye también los cambios generados en `content.js` y `panel-styles.js`.

Los adaptadores de Telegram están en `bulk-page.js`, `manual-page.js`, `photo-page.js` y `backup-page.js`. El motor de partes compartido está en `bulk-engine.js`. `backup-core.js` se ocupa de las identidades, rutas y registros de respaldo. Las pruebas no requieren una cuenta de Telegram ni una conexión con el servicio.

Al informar un fallo, indica la versión de la extensión, el navegador, Web K o Web A, la acción realizada y el mensaje de error. Usa únicamente capturas o registros donde hayas ocultado información privada. No adjuntes tus carpetas de respaldo, datos de sesión, códigos de acceso ni archivos de progreso con datos reales.

Mantén los permisos limitados y las donaciones opcionales. Ninguna contribución debe enviar los mensajes o archivos del usuario a servicios del proyecto.
