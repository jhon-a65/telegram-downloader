# Contributing

Bug reports, feature ideas and translation improvements are welcome in **English or Spanish**. Start with [README.md](README.md) or [README.es.md](README.es.md).

## Development

Use Node.js 22 or later:

```sh
npm ci
npm run build
npm run check
npm test
```

Edit `panel.html` and `panel.css` for layout. Include the generated `content.js` and `panel-styles.js` after running the build.

## English and Spanish

- `panel.html` and adapter messages use stable Spanish source keys.
- `translations/en.json` maps those keys to English. Preserve every `{placeholder}` and the meaning of download limits, permissions and completion status.
- `i18n-runtime.js` translates UI text and known status templates. `i18n.js` is generated by the build and must be included in changes.
- Pass filenames, topic titles and Telegram text as opaque values. Never translate or rename user content, stored paths or progress keys.
- The panel selector stores only `tgLocalLanguage`. Browser-managed names/descriptions are in `_locales/en/messages.json` and `_locales/es/messages.json`.
- Run language tests and the full suite after changing message templates. Unknown server errors stay verbatim so their diagnostic information is preserved.

## Download adapters

`bulk-page.js`, `manual-page.js`, `photo-page.js` and `backup-page.js` adapt Telegram Web. `bulk-engine.js` handles ordered parallel chunks. `backup-core.js` owns stable identities, paths and backup records. Tests use simulated sessions and disk access; they do not require a Telegram account.

Keep permissions minimal, donations optional and file completion durable. Do not add telemetry or send a user's messages/files to another service.

## Report a problem

Use the [bug report form](https://github.com/jhon-a65/telegram-downloader/issues/new/choose). Include the extension version, browser, Web K/Web A, interface language, steps and the error text. Use screenshots or logs only after removing private content. Never attach session files, login codes, real backup manifests or private media.

## Reproduce documentation previews

Previews contain sample data, not a real Telegram session. With Node dependencies installed, `node scripts/preview.cjs /path/to/output` exports HTML using the real panel templates and translations. `python scripts/render-previews.py /path/to/output` renders the PNG/GIF assets using optional development dependencies WeasyPrint 66 and Pillow, plus `pdftoppm`. These tools are not needed to install or use the extension.

## En español

Puedes colaborar y reportar problemas en español. Conserva los identificadores, las rutas y los marcadores `{variable}` al traducir. Edita `translations/en.json` y `i18n-runtime.js`, ejecuta `npm run build`, `npm run check` y `npm test`, e incluye los archivos generados. La guía completa está en [README.es.md](README.es.md).
